# Pocket Garage

One front door for the garage apps — live at
https://joshuapopps.github.io/popps-garage/

- **Evo Wiring Planner** — build a harness you can trace at midnight.
  https://joshuapopps.github.io/evo-wiring-planner/
- **Carb Tune Journal** — the jetting notebook.
  https://joshuapopps.github.io/carb-tune-journal-pwa/
- **Bike Maintenance Log** — the service tracker.
  https://joshuapopps.github.io/bike-maintenance-log-pwa/
- **Pocket Garage Dyno** — the dyno app.
  https://joshuapopps.github.io/popps-garage-dyno/

Plain HTML/CSS, no backend. Same Evo visual system as the apps
(cream paper, black ink, graph grid, typewriter type, red accent).

Card pictures live under `assets/` as self-contained SVG files — each one
carries its ink-on-graph-paper drawing embedded, so the page has no
external image dependencies.
